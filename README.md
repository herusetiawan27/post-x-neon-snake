# Neon Snake — built from ONE prompt

A polished Snake game in a single HTML file. Open `index.html` in any browser and play — no build step, no libraries.

## The one prompt

> Build a polished Snake game in a single HTML file: canvas rendering, arrow-key and touch controls, score and high score, speed increases as you eat, pause and game-over screens, dark neon style.

That single prompt produced the whole game: `index.html` (canvas, HUD, on-screen d-pad, swipe controls, demo autopilot).

## How to play

- **Steer:** Arrow keys / WASD, swipe on the board, or the on-screen d-pad
- **Pause:** Space, P, or the Pause button
- **Goal:** Eat the glowing orbs. Every 4 orbs the snake gets faster. Don't hit the walls or yourself.
- **Best score** is saved in your browser (localStorage).

## Demo mode (for the video)

Open `index.html?demo=1` — the snake plays itself with a simple autopilot, so the game can be recorded hands-free.
